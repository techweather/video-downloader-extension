Installation complete

dlwithit is now in your Applications folder. Launch it from there or from Spotlight.

If you chose to install a browser extension:

  • Firefox — a window should have opened with an "Add" confirmation. Click Add to finish.
  • Chrome — a Chrome Web Store page should have opened. Click "Add to Chrome" to finish.

If the browser window didn't open, the extension files were still installed alongside the app and can be installed manually:

  • Firefox: open Firefox and drag dlwithit-connector-firefox-v1.0.0.xpi from the Resources/extensions/firefox folder inside the app onto any Firefox window.
  • Chrome: open chrome://extensions, enable Developer mode, click "Load unpacked," and select the Resources/extensions/chrome folder inside the app.

Don't use Firefox or Chrome? Copy a link and press ⌘V in the dlwithit window, or click + in its toolbar — works for Safari, Edge, or any other source.
