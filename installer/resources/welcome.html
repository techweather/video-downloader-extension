Welcome to dlwithit

dlwithit is a Mac app for downloading videos and images from the web. This installer will:

  • Install the dlwithit app to your Applications folder.
  • Optionally set up the Firefox extension — Firefox will open with a one-click confirmation prompt.
  • Optionally set up the Chrome extension — Chrome will open to the Chrome Web Store listing.

You can pick which browser extensions to install on the next screen. The app itself is required.
